# Lynk OSN 仪表歌曲列表与专辑封面桥接 0.3.2 · 实验验证版

特定 OneOS / Android 9 车机的 USB 媒体代理实验。提供五首 MIDI、完整测试列表、当前曲与编号封面。不是屏幕镜像，也不是通用第三方音乐播放器桥接器。

## 本版内容

- appSource 来源同步、统一歌曲 ID，以及包含五张 Bitmap 的 typed 列表回调。
- JSON/PFD 列表、当前曲、状态和进度推送。
- “卸载自身（先停止测试并恢复）”，恢复分支成功后进入系统卸载确认。
- 源码采用 GPL-3.0-only；MIDI 的来源与独立许可见仓库通知文件。

## 验证边界

已通过 Java/D8 构建与 API28 签名检查；独立构建检查接口快照、素材校验值及代码一致性。这些离线检查不代表所有车机固件上的显示、播放和卸载功能均能正常工作。

停车低音量测试。测试期间不要强停或直接卸载；结束先恢复原车服务并导出所需日志。180 秒主进程自动恢复、185 秒独立恢复均为尽力机制，不覆盖断电/整包强停等情况。
